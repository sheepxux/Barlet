# Barlet 接口文档

1.0 没有自己的 HTTP 服务，所以没有 Swagger，也不在 Apifox 里维护。运行中的应用不调用我们自己的后端。

两边协作的接口是进程内的 Swift 类型，放在同一个工程里，界面层和动作层都引用它。改签名、改字段或改返回值时，先改这份文档，再改代码。

下面的名字是合同。实现可以拆文件，但调用方只认这些类型。

## 动作

```swift
enum MediaCommand: String, Codable {
    case playPause
    case next
    case previous
    case mute
}

enum KeyModifier: String, Codable {
    case command
    case shift
    case option
    case control
}

struct KeyChord: Codable, Equatable {
    var key: String
    var modifiers: Set<KeyModifier>
}

enum BarAction: Codable, Equatable {
    case keystroke(KeyChord)
    case media(MediaCommand)
    case setVolume(Double)      // 0...1，绝对音量
    case setBrightness(Double)  // 0...1，内建显示器
}

enum ActionResult: Equatable {
    case done
    case needsAccessibility
    case unavailable
}

@MainActor
protocol ActionRunning: AnyObject {
    var volume: Double? { get }
    var brightness: Double? { get }
    var accessibilityGranted: Bool { get }

    func perform(_ action: BarAction) -> ActionResult
    func revealAccessibilitySettings()
}
```

| 方法或属性 | 行为 |
| --- | --- |
| `volume` | 默认输出设备的当前音量，范围 0...1。没有默认输出设备时返回 `nil` |
| `brightness` | 内建显示器的当前亮度，范围 0...1。没有可调的内建显示器时返回 `nil`。界面据此隐藏亮度 |
| `accessibilityGranted` | 进程现在是否已被授予辅助功能 |
| `perform(.keystroke)` | 已授权则把这组键发给前台应用，返回 `done`。未授权则不发送，返回 `needsAccessibility` |
| `perform(.media)` | 发送对应的系统媒体事件，返回 `done`。不需要辅助功能权限 |
| `perform(.setVolume)` | 把默认输出设备设到这个绝对值。值会被夹到 0...1。没有设备时返回 `unavailable` |
| `perform(.setBrightness)` | 设置内建显示器。不可用时返回 `unavailable`，不改变其他显示器 |
| `revealAccessibilitySettings` | 打开系统设置里 Barlet 的辅助功能页 |

滑块在拖动过程中连续调用 `setVolume` 或 `setBrightness`。调用必须在主线程上可以快速返回；耗时的设备访问留在动作层内部。

## 前台应用

```swift
@MainActor
protocol FrontAppObserving: AnyObject {
    var bundleIdentifier: String? { get }
    var onChange: (@MainActor (String?) -> Void)? { get set }
}
```

`bundleIdentifier` 是当前前台应用的 bundle id。没有前台应用时为 `nil`。应用切换时调用 `onChange`，参数是新的 bundle id。界面层只根据这个字符串选预设，不查询应用内部的焦点控件。

## 按钮和预设

```swift
struct BarButton: Codable, Identifiable, Equatable {
    var id: UUID
    var title: String
    var symbol: String
    var enabled: Bool
    var action: BarAction
}

@MainActor
enum ProfileCatalog {
    static func builtin(for bundleIdentifier: String) -> [BarButton]
}
```

`builtin(for:)` 对需求文档里的六个 bundle id 返回那一组按钮，`enabled` 全部为 `true`，`id` 在同一次运行里稳定。其他 bundle id 返回空数组。

这六个 id 是：

| 应用 | Bundle ID |
| --- | --- |
| Safari | `com.apple.Safari` |
| 访达 | `com.apple.finder` |
| 邮件 | `com.apple.mail` |
| 备忘录 | `com.apple.Notes` |
| 信息 | `com.apple.MobileSMS` |
| 预览 | `com.apple.Preview` |

界面层决定最终显示哪一组：`BarletDocument` 里已经有这个 bundle id，就用文件里的按钮；没有，就用 `builtin(for:)`。

## 本机文档

文件格式和路径见 [技术方案](技术方案.md) 的数据设计。界面层负责读写。动作层不打开这个文件。

```swift
struct BarletDocument: Codable, Equatable {
    var schemaVersion: Int
    var settings: BarletSettings
    var profiles: [String: AppProfile]
}

struct BarletSettings: Codable, Equatable {
    var launchAtLogin: Bool
}

struct AppProfile: Codable, Equatable {
    var buttons: [BarButton]
}
```

`schemaVersion` 不是 `1` 时，读取方返回 `nil`，并且不得写回文件。

## 唯一的网络读取

P1。菜单栏「检查更新」读取落地页上的静态文件，不带身份，不带本机信息。

```http
GET /version.json
```

```json
{
  "version": "1.0.0",
  "downloadURL": "https://example.com/Barlet.dmg"
}
```

| 字段 | 含义 |
| --- | --- |
| `version` | 落地页当前提供的版本，语义化版本 |
| `downloadURL` | 浏览器可以直接下载的 dmg |

比较结果新于正在运行的版本时，用默认浏览器打开 `downloadURL`。超时、离线、字段缺失或状态码不是 200，都当作没有更新，不弹错误。

正式域名替换 `example.com` 时，只改应用里的这个地址常量，不改上面的字段。
